# Assets

Esta pasta centraliza os recursos visuais e sonoros do jogo.

## Organização

* `imagens/`: sprites da aranha, alimentos, obstáculos, fundos e ícones.
* `sons/`: efeitos sonoros de coleta de itens, colisões e músicas de fundo.
* `fontes/`: fontes tipográficas utilizadas na interface do jogo.

## Boas práticas

* Use nomes de arquivo descritivos e sem espaços.
* Prefira formatos leves (`.png`, `.ogg`, `.wav`, `.ttf`).
* Registre a origem dos assets utilizados (quando externos).
* Mantenha os arquivos organizados para facilitar a manutenção e evolução do projeto.
