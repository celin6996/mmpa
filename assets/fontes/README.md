# Créditos

O desenvolvimento deste projeto foi realizado com base em conhecimentos gerais de programação, materiais de estudo e apoio de ferramentas de auxílio como o ChatGPT, utilizado para esclarecimento de dúvidas, sugestões de estruturação e apoio na implementação de funcionalidades.

## Ferramentas utilizadas

* Linguagens e tecnologias estudadas em aula e prática pessoal
* Editor de código (ex.: VS Code)
* ChatGPT como ferramenta de apoio para orientação e revisão de ideias

## Observações gerais

* O projeto é inspirado no clássico jogo da cobrinha, adaptado com a temática de uma aranha como personagem principal.
* O objetivo foi aplicar conceitos de lógica de programação, manipulação de arquivos e organização de projeto.
