# Código-fonte (`src`)

Esta pasta contém os módulos principais do jogo da aranha.

## Arquivos

* `jogo.py`: loop principal do jogo, controle de eventos, atualização de estados e renderização.
* `config.py`: constantes globais do projeto (tamanho da tela, cores, FPS e caminhos).
* `funcoes.py`: funções auxiliares de lógica e regras do jogo.
* `sprites.py`: carregamento, organização e recorte de spritesheet.
* `dados.py`: leitura e gravação de dados como recordes e ranking.

## Dica de evolução

Quando o projeto crescer, mantenha os módulos pequenos e separados por responsabilidade. Isso facilita manutenção, testes e futuras melhorias no jogo.
